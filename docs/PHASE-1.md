# Project foundation

This project uses Next.js, Firebase Authentication, Cloud Firestore, Firebase Cloud Functions, Cloudflare R2, and Cloudflare Workers with OpenNext. See [TURNOVER-SETUP.md](TURNOVER-SETUP.md) for current setup, security, and deployment instructions.

The public storefront is `/`, the administrator console is `/admin`, and the moderator review workspace is `/moderation`. Seller listings remain private until approved. The full current source is generated in [PHASE-3-CODE.md](PHASE-3-CODE.md) with `npm run docs:code`.
